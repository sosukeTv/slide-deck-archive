# 🎤 Monthly Deck & Archive (월간 발표 아카이브)

> **팀원 20명을 위한 정기 월간 발표 및 지식 공유 플랫폼**  
> 발표 당일에는 **[인터랙티브 슬라이드 모드]**로 프로젝터/화면공유를 진행하고,  
> 발표 후에는 팀원들이 슬랙/팀즈 링크를 타고 들어와 읽을 수 있는 **[블로그/문서 모드]**를 지원합니다.

---

## ✨ 핵심 기능

1. **듀얼 뷰 (Dual-View)**:
   - **발표 슬라이드 모드 (Presentation View)**: 방향키(`←`, `→`), 스페이스바, 터치 스와이프로 넘기는 16:9 슬라이드, 발표 경과 시간 타이머, 전체화면(`F`), 슬라이드 전체 목차(`O`).
   - **블로그/문서 모드 (Reading View)**: 발표 불참자 또는 사후 복습용 스크롤 리딩 모드, 공유 링크 복사 지원.
2. **유튜브 영상 요약 및 임베드**:
   - 상단 또는 본문 중간에 16:9 반응형 유튜브 플레이어 자동 탑재.
3. **인포그래픽 & 다이어그램 (Mermaid.js)**:
   - 복잡한 프로세스나 사고 흐름을 플로우차트로 자동 시각화.
4. **마크다운 기반 초간단 관리**:
   - `src/content/` 폴더에 `.md` 파일만 넣으면 웹사이트에 즉시 자동 반영.
5. **완전 무료 호스팅 (0원)**:
   - Vercel 또는 Cloudflare Pages에 연동하여 평생 무료 운영 가능 (일본 도쿄 엣지 서버 지원).

---

## 🚀 로컬 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
cmd /c npm install

# 2. 로컬 개발 서버 실행
cmd /c npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## ✍️ 새 발표 자료 올리는 법

`src/content/` 폴더에 새 마크다운 파일(예: `2026-11-my-topic.md`)을 생성합니다:

```markdown
---
id: "2026-11-my-topic"
title: "11월 정기 발표: 발표 제목"
subtitle: "발표 부제목 또는 요약"
date: "2026-11-20"
category: "Tech" # Security, Life, Tech, Trends 중 선택
author: "발표자 이름"
description: "팀원들에게 전하고 싶은 핵심 내용 2~3줄 요약"
youtubeId: "영상ID" # 선택사항 (없으면 생략)
youtubeTitle: "영상 제목"
tags: ["키워드1", "키워드2"]
thumbnail: "https://images.unsplash.com/photo-1517245386807-bb43f82c33c4?w=800&auto=format&fit=crop&q=80"
---

# 슬라이드 1: 타이틀
여기에 첫 번째 슬라이드 내용 작성...

---

# 슬라이드 2: 두 번째 내용
여기에 두 번째 슬라이드 내용 작성...

---

# 슬라이드 3: 다이어그램 예시
\`\`\`mermaid
flowchart LR
    A[아이디어] --> B[기획 및 정리]
    B --> C[슬라이드 자동 생성]
\`\`\`
```

## 🌐 Vercel에 0원(무료)으로 배포하기

1. GitHub에 본 저장소 코드를 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **"Add New Project"**를 클릭합니다.
3. GitHub 저장소를 선택하고 **"Deploy"**를 누르면 끝납니다.
4. 이후 새 마크다운 파일을 GitHub에 올릴 때마다 1분 내로 웹사이트에 자동 반영됩니다.
